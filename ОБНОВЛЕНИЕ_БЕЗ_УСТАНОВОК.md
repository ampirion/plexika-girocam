# V13.37 — Giro7

## Обновление через браузер — ничего устанавливать не нужно

1. Распакуйте **Giro7.zip**, откройте папку `plexika-girocam-v7`.
2. Откройте существующий https://github.com/ampirion/plexika-girocam → **Add file → Upload files**.
3. Загрузите содержимое папки в корень репозитория, сохранив `src`. Не загружайте ZIP вместо файлов и не создавайте дополнительную внешнюю папку.
4. Замените также **wrangler.jsonc**: там добавлены EXPORTS и миграция `v6-temp-exports`. Обязательны все файлы `src`, включая **export-store.js**, **open.html**, **phone.html**. Нажмите **Commit changes** в `main`.
5. Дождитесь успешного Deploy в существующем Cloudflare Worker. https://plexika-girocam.ampirion.workers.dev/health должен показать **protocol:7, ready:true, exportsReady:true, public:true, limit:100**.
6. Откройте **V13.37.html**, создайте новый QR; старую телефонную вкладку закройте. Для сайта редактора замените его index.html новым V13.37.html.

Имя Worker и старые миграции сохранены. Новый аккаунт, платный тариф, домен и новый секрет не требуются. Существующий PAIRING_KEY остаётся в настройках Cloudflare, в архиве секретов нет. Не публикуйте личный ключ в GitHub и не передавайте его в QR.

## Что изменено

- Адрес сервера спрятан в дополнительных настройках, но остаётся изменяемым.
- В упрощённой сцене видео остаётся плоскостью; импортированные модели обозначены габаритным боксом, именем и размерами, не шаром.
- Общий сеанс Cloudflare: **20 минут**, затем новое подключение. Активный личный сеанс по ключу — без таймера и вне общей квоты 100. Ожидание подключения и потеря связи всё ещё имеют технические таймауты; бесплатные квоты платформы не отменены.
- При выбранном личном доступе по ключу доступна панель **«Общий Cloudflare · администратор»**: число подключённых телефонов, остановка общих сеансов и запрет новых общих входов на 0–1440 минут. Ноль означает остановку без последующего запрета. **Личные подключения не останавливаются.** Это управление именно Worker, не чужими PeerJS/ручными соединениями.
- PeerJS QR появляется сразу, до ответа облака. Это не гарантирует доступность самого PeerJS в любой сети.
- Ручной обмен кодами использует прямой WebRTC, не Worker relay. Страница телефона может открываться с Worker, а установление связи — обращаться к STUN. TURN не добавлен: некоторые NAT/сети могут не соединиться.
- На iPad в редакторе: **«Включить на iPad»**, без QR и второго устройства; изменения объектов видны сразу. Нужны разрешение датчиков и защищённый контекст браузера. Freeze, исходная камера и выключение сохранены.
- У «Входные данные» и «Слои и свойства» убраны кнопки разворачивания; эти боковые панели не максимизируются и горячей клавишей.

## HTML на телефоне — основной сценарий

**Создайте новый HTML из V13.37. Старые скачанные файлы сами не обновляются.** Обычный экспорт по умолчанию скачивает HTML, не создаёт ссылку на компьютере.

1. Откройте этот HTML в браузере телефона, который исполняет HTML/JavaScript, а не показывает файл как текст.
2. Нажмите значок телефона → **«Включить гирокам»**.
3. Если это локальный файл (`file:`), HTML загружается на ваш Worker. Видны полоса загрузки и проценты фактически отправленных порций. Затем HTTPS-сцена открывается **в той же вкладке**.
4. Если браузер требует разрешение датчиков после перехода, нажмите **«Включить гирокам»** ещё раз. Разрешение iOS/другого браузера нельзя автоматически перенести через навигацию. В браузере без такого требования запуск автоматический.
5. При включении панель сворачивается, не выключая гирокам. Значок телефона раскрывает её снова. **× выключает гирокам**, а при загрузке отменяет её. Значок телефона лишь скрывает/показывает настройки. Отдельная маленькая иконка поворота запрашивает ориентацию телефона; при запрете браузера используйте автоповорот ОС.

Снимок HTML, а не видеопоток камеры, отправляется на сервер только при нажатии включения из локального файла. **Любой обладатель временного URL сможет открыть сцену**. Срок — 20 минут от создания загрузки, не продлевается чтением. До **16 МиБ**, до 20 временных загрузок одновременно. Фрагменты удаляются серверным alarm и при обращении после срока; фактический запуск alarm зависит от планировщика Cloudflare. Скачанные копии и скриншоты не удаляются. Открытая вкладка проверяет срок и перезагружается на страницу завершения; сон/сворачивание может отложить визуальную реакцию.

Опциональная галочка создания ссылки при экспорте на компьютере оставлена дополнительным способом. Её окно компактное, без максимизации и наложения кнопок. Для автономного файла выбирайте экспорт «Без интернета»; опциональный онлайн-экспорт по-прежнему требует доступа к существующему CDN просмотрщика.

### Ручной способ без отправки файла сохранён

Откройте https://plexika-girocam.ampirion.workers.dev/open → **«Выбрать HTML на устройстве»**. Файл читается локально, на сервер не загружается. Затем включите гирокам. Это также запасной путь для файлов больше лимита временной ссылки и браузеров, которые не исполняют локальный HTML. Если ОС показывает файл только как текст/встроенное вложение, JavaScript этого файла не сможет сам начать загрузку: нужен настоящий браузер или ручной выбор.

## «Использовать камеру для ZOOM»

Галочка есть в мобильном HTML-просмотрщике и на странице подключённого телефона; запрос можно включить также из панели компьютера. Нужны HTTPS, разрешение камеры и включённые датчики. Запрашивается задняя камера, звук не запрашивается. Кадры обрабатываются **локально**, не отправляются на Worker/компьютер. При удалённом управлении передаются только числовая поза камеры и служебное состояние.

Трекер находит контрастные точки, сопоставляет небольшие области между кадрами и оценивает изменение расстояний между точками. Увеличение масштаба двигает виртуальную камеру вперёд, уменьшение — назад. Общий сдвиг и вращение в плоскости подавляются. Это **оценка, не измеритель расстояния**: однотонная поверхность, темнота, быстрый поворот/наклон, параллакс, двигающиеся предметы и смена объектива могут давать ошибки. Наводите камеру на неподвижные детали. Два пальца остаются надёжным ручным способом приближения.

Freeze удерживает и оптический ZOOM без накопления скачка. Выключение галочки/гирокама, уход со страницы или сворачивание останавливают видеодорожки камеры. Старый экспериментальный акселерометр больше не предлагается вместо камеры в основной панели.

## Анимация и тень

Текст и псевдотень — отдельные объекты. Экспорт теперь добавляет зависимую тень к покадровому движению хозяина и считает её положение/масштаб/прозрачность штатной функцией редактора. В просмотрщике для тени восстановлены двусторонность, смещение относительно пола и отключение записи глубины, чтобы убрать пропадание из-за обратной стороны/конкуренции с полом. Видимость через непрозрачные стены/пол не включается: реальная окклюзия сохраняется. Исходные материалы редактора после экспорта восстанавливаются.

Существующие каналы видео, импортированных клипов, движения объектов, процедурных текстур/масок и камеры не заменяются упрощённым видео. Для полной сцены удалённого телефона по-прежнему нужно включить **«Добавить видео и анимацию»**, а затем воспроизведение на телефоне.

## Сохранённое поведение

Упрощённая/полная сцена — взаимоисключающий выбор. Полная сцена содержит настоящие 3D-модели, текстуры и, по отдельной галочке, видео/анимацию. Это локальная отрисовка, **не непрерывная видеотрансляция**. После изменения объектов на компьютере обновите удалённый снимок кнопкой обновления сцены. На самом iPad локальные правки не требуют обновления снимка. Датчики включаются на телефоне; отдельной галочки управления камерой на компьютере нет. Для статичной сцены нет ложной кнопки воспроизведения видео. Точная запись, повтор потерянных пакетов и Undo/Redo сохранены.

## Проверки и ограничения

**Интерактивно, Chromium с мобильной эмуляцией:** реальный экспорт обычного файла, открытие файла → отправка порций → просмотр Worker в той же вкладке; сворачивание/раскрытие панелей и компактные иконки; реальный getUserMedia с тестовым видеоустройством, остановка его дорожек; камера с синтетически увеличивающимся изображением → числовая поза телефона → реальная камера редактора через Worker, без передачи кадров. Через штатное меню создан текст и включено плавание: экспортированные текст и тень действительно двигаются. Видео, импортированный клип, полная сцена/возврат к упрощённой при ошибке, Freeze/Home/сдвиг двумя пальцами, ручной WebRTC, QR до PeerJS, iPad-кнопка и живая правка, ручной выбор файла без загрузки, горизонтальный вид и возврат ручного управления. Точная запись 105 отсчётов, повтор потерянных пакетов, Undo/Redo; обычная запись и остановка через ×.

**Статически/серверно:** синтаксис; авторизация и хеш отправленного HTML; сроки 20 минут/очистка и бессрочный активный личный сеанс с моделируемыми часами; административная остановка только общего режима. Алгоритм точек: увеличение/уменьшение масштаба, подавление чистого сдвига и вращения проверены на синтетических изображениях. Проверка 100 WebSocket-входов/FIFO ранее выполнена в V13.36; текущий алгоритм очереди не изменён.

**Не проверено:** физические Samsung/iPad и качество оптического ZOOM на реальной камере, внешние сети, обновление вашего рабочего Cloudflare. Не заявляется исчерпывающая проверка всех сочетаний анимации и всех ракурсов тени. Бесплатные квоты Cloudflare сохраняются; личный ключ не отменяет лимиты платформы. Тесты — локальный Worker, не рабочий сервер.
